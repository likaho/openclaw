# Enterprise Portal

Browser-first onboarding portal for OpenClaw Enterprise.

## Features

- Self-serve signup
- Invite acceptance
- OIDC login + callback + refresh/logout
- Tenant/workspace bootstrap
- Channel catalog + connection + verification
- Skills catalog + install + configure

## Local run

```bash
pnpm --filter @openclaw/enterprise-portal start
```

Default port: `4020`.
